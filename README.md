# smart_vnimanie_foundraising

**Демо-проект** для [благотворительного фонда «Внимание»](https://fondvnimanie.ru) — платформа для сбора пожертвований в криптовалюте (ETH) с прозрачным учётом операций и обновлением прогресса сбора в реальном времени.

> ⚠️ Это учебная/демонстрационная версия, не предназначенная для приёма реальных пожертвований в production без дополнительной настройки и аудита.

## О проекте

Сайт выполнен в фирменной стилистике фонда «Внимание» и демонстрирует, как можно объединить классический веб-интерфейс с блокчейном Ethereum для прозрачного благотворительного фандрайзинга.

### Основные возможности

- **Криптопожертвования** — донаты в ETH через MetaMask или ручной ввод адреса кошелька
- **Смарт-контракт** — фиксация каждого перевода в блокчейне (Solidity + Truffle)
- **Учёт операций** — синхронизация транзакций с базой данных MySQL
- **Прогресс-бар в реальном времени** — отображение собранной суммы и процента от цели по каждому проекту
- **История донатов** — лента всех пожертвований с хешами транзакций
- **Топ доноров** — рейтинг участников по сумме взносов
- **Несколько проектов** — отдельные цели сбора для разных инициатив фонда

## Стек технологий

| Слой | Технологии |
|------|------------|
| Frontend | HTML, CSS, JavaScript, Web3.js, MetaMask |
| Backend | Node.js, Express |
| Блокчейн | Solidity, Truffle, Ganache |
| База данных | MySQL |


## Полезные команды

```bash
npm run dev                  # Сервер с hot-reload (nodemon)
npm run view-donations-db    # Просмотр донатов в MySQL
npm run view-donations-bc    # Просмотр донатов в блокчейне
```

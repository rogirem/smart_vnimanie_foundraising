# smart_vnimanie_foundraising

**Демо-проект** для [благотворительного фонда «Внимание»](https://fondvnimanie.ru) — платформа для сбора пожертвований в криптовалюте (ETH) с прозрачным учётом операций и обновлением прогресса сбора в реальном времени.

> ⚠️ Это учебная/демонстрационная версия, не предназначенная для приёма реальных пожертвований в production без дополнительной настройки и аудита.

## О проекте

Сайт выполнен в фирменной стилистике фонда «Внимание» и демонстрирует, как можно объединить классический веб-интерфейс с блокчейном Ethereum для прозрачного благотворительного фандрайзинга.

### Основные возможности

- **Криптопожертвования** — донаты в ETH через MetaMask или ручной ввод адреса кошелька
- **Смарт-контракт** — фиксация каждого перевода в блокчейне (Solidity + Truffle)
- **Учёт операций** — синхронизация транзакций с базой данных MySQL
- **Прогресс-бар в реальном времени** — отображение собранной суммы и процента от цели по каждому проекту
- **История донатов** — лента всех пожертвований с хешами транзакций
- **Топ доноров** — рейтинг участников по сумме взносов
- **Несколько проектов** — отдельные цели сбора для разных инициатив фонда

## Быстрый старт

### 1. Установка зависимостей

```bash
npm install
npm install -g truffle
```

### 2. База данных MySQL

```bash
mysql -u root -p < database.sql
```

### 3. Переменные окружения

Скопируйте `.env.example` в `.env` и заполните значения:

```bash
cp .env.example .env
```

```env
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=your_password
DB_NAME=fondvnimanie
PORT=3000
CONTRACT_ADDRESS=
FACTORY_ADDRESS=
```

### 4. Локальный блокчейн

Запустите [Ganache](https://trufflesuite.com/ganache/) на порту `8545` (Chain ID: `1337`).

### 5. Деплой смарт-контракта

```bash
npm run compile
npm run migrate
```

Скопируйте адрес контракта из вывода команды и укажите его в `.env` как `CONTRACT_ADDRESS`.

### 6. Запуск сервера

```bash
npm start
```

Откройте в браузере: [http://localhost:3000](http://localhost:3000)

## Настройка MetaMask

1. Добавьте сеть Ganache:
   - **Название:** Ganache Local
   - **RPC URL:** `http://127.0.0.1:8545`
   - **Chain ID:** `1337`
   - **Валюта:** ETH
2. Импортируйте тестовый аккаунт из Ganache для отправки донатов.

## API

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| GET | `/api/projects` | Список проектов и прогресс сбора |
| GET | `/api/donations` | История пожертвований |
| GET | `/api/leaderboard` | Топ доноров |
| GET | `/api/contract-info` | Адрес и ABI контракта |
| POST | `/api/donations/sync` | Синхронизация доната из блокчейна в БД |
